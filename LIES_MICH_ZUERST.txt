RoadSense v4 – lokale Schlüssel, Render bleibt leicht
=====================================================

DIE WICHTIGSTE REGEL
--------------------
Echte Schlüssel liegen nur lokal auf deinem PC:

  %LOCALAPPDATA%\RoadSense\.env

Diese Datei liegt AUSSERHALB des GitHub-Ordners.
Sie wird bei GitHub-Desktop-Updates nicht gelöscht oder ersetzt.
Sie wird NICHT auf GitHub und NICHT auf Render gespeichert.

Darin können liegen:
  ANTHROPIC_API_KEY
  ZAPIER_WEBHOOK_URL
  AUSWERTUNG_TOKEN
  SECRET_KEY


ARCHITEKTUR
-----------
Render hostet nur die RoadSense-Webseite und die Beispielstrecken.

  Browser
     |-- normale Webseite --> Render
     |
     `-- Fotos / Claude / Zapier --> direkt per HTTPS/Tailscale --> dein Auswerte-Laptop

Dadurch:
  - bleibt Render Free klein und RAM-schonend,
  - landen die großen Fotos nicht mehr zur Auswertung auf Render,
  - braucht Render keinen Claude-Key und keinen Verbindungsschlüssel,
  - bleibt die Bildauswertung auf deinem Laptop.


ERSTER START NACH DEM UPDATE
----------------------------
1. Auswerte_Laptop_starten.bat doppelklicken.
2. Falls im aktuellen Projektordner noch eine alte .env liegt, wird sie automatisch
   nach %LOCALAPPDATA%\RoadSense\.env übernommen und anschließend aus dem
   GitHub-Ordner entfernt.
3. Zwei schwarze Fenster offen lassen:
     - RoadSense lokal auf Port 8000
     - Tailscale Funnel
4. Das Startfenster zeigt:
     - die feste Tailscale-Adresse, z. B. https://christian-yoga....ts.net
     - den lokalen AUSWERTUNG_TOKEN
5. In der ONLINE-App einmal "Neue Strecke" öffnen und dort unter
   "Auswerte-Laptop verbinden" Adresse + Token eintragen.
   Beides wird nur im localStorage dieses Browsers gespeichert.

Danach reicht bei jedem Windows-Neustart wieder:
  Doppelklick auf Auswerte_Laptop_starten.bat

Die Browser-Verbindung bleibt normalerweise gespeichert.


RENDER – EINMALIG ALTE SCHLÜSSEL ENTFERNEN
-------------------------------------------
Nach dem Deploy dieser Version bei Render unter Environment alte persönliche
Werte löschen, falls sie noch vorhanden sind:

  ANTHROPIC_API_KEY
  ZAPIER_WEBHOOK_URL
  AUSWERTUNG_URL
  AUSWERTUNG_TOKEN
  CLAUDE_MODEL

Die neue Version braucht diese Werte auf Render NICHT mehr.
ROADSENSE_ROLE=web kommt aus render.yaml.


CLAUDE-KEY LOKAL EINTRAGEN
--------------------------
Doppelklick auf:
  Lokale_Einstellungen_oeffnen.bat

Dann in der lokalen Datei eintragen:
  ANTHROPIC_API_KEY=...

Speichern und Auswerte_Laptop_starten.bat neu starten.
Der Claude-Key wird nicht in GitHub oder Render gespeichert.


NEUE VERSIONEN / LOOP
---------------------
Bei zukünftigen RoadSense-Versionen nur die Programmdateien im lokalen
GitHub-Ordner ersetzen -> GitHub Desktop -> Commit -> Push.

Die lokale Datei
  %LOCALAPPDATA%\RoadSense\.env
liegt außerhalb des Repositories und bleibt daher unangetastet.

Neue ausgewertete Strecken werden weiterhin im Browser unter
"Oder eine ausgewertete Strecke ansehen" gespeichert (max. 20 pro Browser).


SICHERHEIT
----------
Der lokale Auswerte-Laptop akzeptiert rechenintensive API-Aufrufe nur mit dem
lokalen Verbindungstoken. Der Browser sendet diesen Token direkt per HTTPS an
den Tailscale-Funnel. Render erhält ihn nicht.

Ergebnisbilder und Berichte werden über eine zufällige 128-Bit-Auftrags-ID
abgerufen und nach der vorgesehenen Aufbewahrungszeit wieder gelöscht.
